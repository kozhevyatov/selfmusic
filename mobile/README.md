# SelfMusic для Android и iPhone

Гибрид: экран входа и плеер — нативные (Expo, `expo-audio`), остальной интерфейс — сайт SelfMusic во WebView.

- Музыка играет в фоне, с уведомлением, на экране блокировки и с кнопками наушников (назад / пауза / вперёд); на iPhone — в «Пункте управления» и на экране блокировки.
- Переход к следующему треку делает системный плеер — работает и когда приложение свёрнуто.
- Прослушивания, место в аудиокниге и таймер сна приложение ведёт само, без страницы.
- Скачивание для офлайна: кнопка «Скачать» на сайте качает треки в память телефона. Скачанное играет из памяти (и без сети,
  и без трафика), прослушивания без связи отправляются на сервер позже. Если сервер недоступен и сайт не открылся,
  приложение показывает своё офлайн-окно со скачанными подборками.
- Интерфейс обновляется вместе с сервером: после деплоя новый APK не нужен. Код самого приложения (папка `mobile/`)
  тоже обновляется «по воздуху» через EAS Update — без переустановки (см. ниже).

Только в браузере: эквалайзер и кроссфейд.

## Сборка (на Mac)

```bash
cd selfmusic/mobile
npm install
npx expo install --fix                                   # версии библиотек под Expo SDK 58
npx eas-cli@latest build -p android --profile production # APK для установки и для сайта
```

Сборка идёт в облаке Expo (~10–15 минут). В конце — ссылка на APK: её можно вставить в «Админка → Приложение для Android»
(сервер скачает файл сам) или скачать и загрузить файлом. Новый APK ставится поверх старого, вход и скачанное сохраняются.

## Сборка для iPhone (на Mac)

Один и тот же код, `bundleIdentifier` — `ru.nskarl.selfmusic`. Для установки на iPhone нужен аккаунт Apple Developer
(платный, $99/год): без него Apple не подпишет приложение ни для TestFlight, ни для установки по ссылке.

**Вариант 1 — TestFlight (удобнее всего):**

```bash
cd selfmusic/mobile
npm install && npx expo install --fix
npx eas-cli@latest build -p ios --profile production   # спросит Apple ID, сам создаст сертификаты и профиль
npx eas-cli@latest submit -p ios --latest              # отправит сборку в App Store Connect → TestFlight
```

Через 10–30 минут сборка появится в приложении TestFlight на iPhone. Публиковать в App Store не обязательно.
Новые сборки — поднять `ios.buildNumber` в `app.json`.

**Вариант 2 — установка по ссылке (ad hoc):** `npx eas-cli@latest device:create` (открыть ссылку на iPhone, поставить профиль),
затем `npx eas-cli@latest build -p ios --profile preview`. Ставится только на зарегистрированные устройства.

**Вариант 3 — без платного аккаунта, через Xcode:** `npx expo run:ios --device --configuration Release` с iPhone по кабелю
и бесплатным Apple ID в Xcode. Приложение работает 7 дней, потом нужно поставить заново.

Обновления «по воздуху» (`eas update`) работают на iPhone так же, как на Android.

## Обновления

- **Сайт** (почти весь интерфейс) — обновляется сам при деплое сервера.
- **Код приложения** (`mobile/src`, `App.tsx`) — через EAS Update, без нового APK:
  ```bash
  npx eas-cli@latest update --channel production --message "что поменялось"
  ```
  Приложение скачает обновление при запуске и применит при следующем запуске.
- **Новый APK** нужен, только если поменялись нативные части: библиотеки в `package.json`, плагины и права в `app.json`,
  иконки. Тогда поднимите `version` (и `android.versionCode`) в `app.json` и соберите заново. Обновления «по воздуху»
  привязаны к версии: сборка 1.1.0 получает только обновления, опубликованные из кода с версией 1.1.0.

## Вход

Адрес сервера — тот же, что в браузере (`music.example.ru`, `https://…` или `192.168.1.10:1332` для домашней сети; http разрешён). Пароль не хранится — только ключ входа в зашифрованном хранилище (Keystore на Android, Keychain на iOS). На iPhone при входе по адресу в домашней сети система один раз спросит доступ к локальной сети — его нужно разрешить. Выход из аккаунта на сайте возвращает к экрану входа.

## Как устроено

- `src/session.ts` — сервер, вход, токены; `mediaUrl()` добавляет к потоку и обложкам media-токен (`?mt=`), его выдаёт сервер при входе.
- `src/player.ts` — плейлист `expo-audio`: очередь, экран блокировки, учёт прослушиваний, книги, таймер сна.
- `src/offline.ts` — скачанное: файлы в памяти приложения, индекс, очередь загрузок, прослушивания без связи.
- `src/OfflineScreen.tsx` — окно «нет связи» со скачанными подборками и мини-плеером.
- `src/WebScreen.tsx` — WebView и мост: страница шлёт команды (`frontend/src/lib/native.ts`, `nativePlayer.ts`, `offline.ts`),
  приложение возвращает состояние плеера, скачанного и отступы экрана (WebView — на весь экран, под системными панелями).
