# SelfMusic для Android

Гибрид: экран входа и плеер — нативные (Expo, `expo-audio`), остальной интерфейс — сайт SelfMusic во WebView.

- Музыка играет в фоне, с уведомлением, на экране блокировки и с кнопками наушников (назад / пауза / вперёд).
- Переход к следующему треку делает системный плеер — работает и когда приложение свёрнуто.
- Прослушивания, место в аудиокниге и таймер сна приложение ведёт само, без страницы.
- Интерфейс обновляется вместе с сервером: после деплоя новый APK не нужен. Пересобирать — только когда меняется папка `mobile/`.

Пока только в браузере: эквалайзер, кроссфейд и скачивание для офлайна (в приложении будет нативное скачивание — следующий шаг).

## Сборка (на Mac)

```bash
cd ~/www/selfmusic/mobile
npm install
npx expo install --fix      # подтянет версии библиотек под Expo SDK 58
eas init                    # один раз: привяжет проект к вашему аккаунту Expo (впишет projectId в app.json — закоммитьте)
eas build -p android --profile preview
```

Сборка идёт в облаке Expo (~10–15 минут). В конце — ссылка и QR-код на APK: откройте на телефоне, разрешите установку из этого источника.

## Вход

Адрес сервера — тот же, что в браузере (`music.example.ru`, `https://…` или `192.168.1.10:1332` для домашней сети; http разрешён). Пароль не хранится — только ключ входа в зашифрованном хранилище Android. Выход из аккаунта на сайте возвращает к экрану входа.

## Новая версия приложения

Поднимите `version` и `android.versionCode` в `app.json` и запустите `eas build` ещё раз. Новый APK ставится поверх старого, вход сохраняется.

## Как устроено

- `src/session.ts` — сервер, вход, токены; `mediaUrl()` добавляет к потоку и обложкам media-токен (`?mt=`), его выдаёт сервер при входе.
- `src/player.ts` — плейлист `expo-audio`: очередь, экран блокировки, учёт прослушиваний, книги, таймер сна.
- `src/WebScreen.tsx` — WebView и мост: страница шлёт команды (`frontend/src/lib/native.ts`, `nativePlayer.ts`), плеер возвращает состояние.
